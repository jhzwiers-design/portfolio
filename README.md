# John Zwiers · Portfolio (round 1)

A static site: plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser to view it locally.

- `index.html`: home (Work)
- `about.html`: about and contact
- `work/`: one page per case study
- `assets/`: `style.css`, `site.js`, logo
- `images/`: every image, grouped by project

## Publish on GitHub Pages

The easiest way is GitHub Desktop:
1. File → New repository (for example `portfolio`), then copy everything in this folder into it.
2. Commit to `main`, then Publish repository (untick "Keep this code private").
3. On github.com, open the repo → Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. After a minute the site is live at `https://jhzwiers-design.github.io/portfolio/`.

Uploading in the browser instead? GitHub's web uploader takes 100 files at a time, so upload in batches:
1. `index.html`, `about.html`, `README.md`, `.nojekyll`, `assets/`, `work/`
2. `images/laborde-print-ads` and `images/input-output`
3. `images/nasa-rover-posters` and `images/week-of-car-usage`
4. `images/northbrew-tea`, `images/news-gothic-specimen` and `images/jazz-fest-booklet`
5. `images/mitsubishi-power-guide`, `images/movie-trailer`, `images/covers`, `images/about`, `images/og.jpg` and `media/`

Dashed red boxes on the pages are placeholders for things still to add (notes, photos, email, LinkedIn, résumé).
